# 뉴스 문서 요약 프로젝트

한국어 뉴스 본문을 입력받아 핵심 내용을 생성하는 요약 모델을 실험한 팀 프로젝트입니다. 데이터의 중복·노이즈를 점검하고, KoBART를 파인튜닝한 뒤 ROUGE와 반복률·사실성 관련 오류를 함께 살펴봤습니다.

## 프로젝트 목표

- 뉴스 본문에서 핵심 정보를 간결하게 요약합니다.
- 중복 기사와 품질이 낮은 학습 정답이 모델 평가와 학습에 미치는 영향을 확인합니다.
- ROUGE 점수만으로는 알기 어려운 반복, 고유명사·숫자 오류, 문장 품질을 사례와 함께 분석합니다.

## 최종 실험 설정

| 항목 | 설정 |
|---|---|
| 모델 | `gogamza/kobart-base-v2` |
| 학습 데이터 | 노이즈 정리 버전 v2, 18,150건 |
| 검증 데이터 | v2, 2,084건 |
| 평가 데이터 | 2,740건 |
| 입력 / 생성 길이 상한 | 512 / 160 토큰 |
| 학습률 | `3e-5` |
| 유효 배치 크기 | 16 (배치 4 × gradient accumulation 4) |
| 학습 | 최대 3 epoch, 검증 loss 기반 체크포인트 선택 및 조기 종료 |
| 생성 | Beam search 4, 6-gram 반복 억제 |

## 기록된 결과

| 지표 | 결과 |
|---|---:|
| ROUGE-1 / ROUGE-2 / ROUGE-L | 0.6529 / 0.5449 / 0.5685 |
| 정답 노이즈 제외 ROUGE-L | 0.5684 |
| train 누수 제외 ROUGE-L | 0.5632 |
| Lead-60 기준선 ROUGE-L | 0.4570 |
| 반복 출력 비율 | 0.15% |
| 평균 생성 길이 | 41.7단어 (정답 평균 42.1단어) |
| 고유명사 원문 포함률 / 숫자 정확도 | 95.00% / 99.20% |

오류 분석에서는 첫 단어가 깨지는 현상이 주요 모델 오류로 확인됐습니다(148건, 5.40%). 반면 반복 억제는 반복률을 낮췄지만 첫 단어 오류까지 해결하지는 못했습니다. 자세한 실험 과정과 사례는 최종 노트북 및 개발 기록을 참고하세요.

## 실행 및 재현 참고

저장소에는 현재 노트북만 포함되어 있습니다. 학습과 전체 분석을 다시 실행하려면 별도로 원본 데이터, 전처리 산출물, `common.py`, 필요한 패키지와 모델 파일을 준비해야 합니다. 일부 노트북은 작성 당시의 로컬 경로를 사용하므로 실행 환경에 맞게 경로를 설정해야 합니다.

또한 기록된 실험은 단일 시드로 수행됐고, 데이터 버전·학습률·디코딩 설정을 비교하는 과정에서 평가 데이터 점수를 사용했습니다. 따라서 위 수치는 최종 일반화 성능의 확정값이라기보다 해당 실험 조건에서 관찰된 결과로 해석해야 합니다. ROUGE는 정답 문구와의 유사도를 측정하므로 요약의 사실성이나 유용성을 단독으로 보증하지 않습니다.
