# 뉴스 요약 프로젝트 개발 기록

이 폴더에는 최종 제출본을 만들기까지의 데이터 탐색, 전처리, 모델 실험 및 오류 분석 노트북을 모았습니다. 저장소 루트의 `1조 뉴스요약_최종.ipynb`는 최종 제출본이며, 이 폴더는 개발 과정과 보조 실험을 확인하기 위한 기록입니다.

## 구성

- `00_environment_data_kobart.ipynb` ~ `06_project_summary.ipynb`: 환경·데이터 분석, 토큰화, 기준선, 전처리, 중복·노이즈 검토, 모델 실험 및 요약
- `전체_실험_RUN_ALL.ipynb`: 실험 과정을 통합 실행하기 위한 노트북
- `최종본/`: 제출용 노트북, 전체 실험 기록, 재학습·최종 평가 실행 노트북
- `archive/preprocessing_before_consolidation_20260920/`: 전처리 노트북을 통합하기 전의 단계별 기록
- `tmp/`: 통합 실행 노트북 수정 전 보관본

## 실행 참고

노트북에 따라 원본 데이터, 중간 산출물, 모델 체크포인트, `common.py` 및 별도 Python 패키지가 필요합니다. 일부 경로는 작성 당시의 로컬 환경을 기준으로 하므로, 다른 환경에서 실행할 때는 데이터·경로·패키지 설정을 맞춰야 합니다. 이 폴더는 실험 기록 보관용이며 모든 노트북이 단독 실행되도록 구성된 것은 아닙니다.
